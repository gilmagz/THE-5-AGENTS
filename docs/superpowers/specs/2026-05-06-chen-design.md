# Design: חן — סוכנת חקר רשת

**Date:** 2026-05-06  
**Status:** Approved  
**Stakeholders:** ממוקה (orchestrator), יעל (downstream rewriter)

---

## Context

המערכת זקוקה לסוכן עם גישה לאינטרנט שמוצא מקורות אמינים ועדכניים, שומר אותם כקלט ליעל, ומתעד את החיפושים. חן היא LLM + Web tools — אין לה Bash, אין API חיצוני, ואין יכולת להפעיל סוכנים אחרים. ההבדל מ-LLM רגיל: מידע עכשווי ומקורות אמיתיים, לא הזיות.

---

## Architecture

```
משתמש → ממוקה: "מצא מאמר על X" / "מצא ושכתב X"
              ↓
ממוקה (trigger זוהה) → חן: נושא + מילות מפתח
              ↓
חן: 1. Grep ב-Memory/searches.md → cache check (30 ימים)
    2. דינמי? → תמיד מחפשת. אחרת → אם cache hit → דווח קיים
    3. WebSearch + WebFetch על מקורות מבטיחים
    4. סננה לפי קריטריונים, דרגה כל מקור (★)
    5. שמרה כל מקור איכותי כקובץ ב-Content/
    6. הוסיפה entry ל-Memory/searches.md
    7. דווחה לממוקה: רשימת קבצים + דירוגים + לינקים
              ↓
ממוקה (החלטה לפי הבקשה המקורית):
   חיפוש + שכתוב? → בחר ★ הגבוה → הפעל יעל
   רק חיפוש? → דווח רשימה למשתמש
```

**מגבלות מכוונות:** חן לא מפעילה אחרים. רק ממוקה מפעיל יעל אחריה.

## Workflow Detailed

### שלב 1 — Memory check
```
Grep -i על מילות המפתח ב-chen/Memory/searches.md
```
אם נמצא entry בתאריך מ-30 הימים האחרונים:
- אם נושא דינמי (חדשות, מחירים, סטטיסטיקות) → המשך לחיפוש חדש
- אחרת → דווח לממוקה: "כבר חיפשתי X בתאריך Y, יש לי את <files>. רוצה לעבוד על הקיים או לחפש מחדש?"

### שלב 2 — Search
- WebSearch: 2-3 שאילתות מנוסחות
- בחר 5-8 תוצאות מבטיחות
- WebFetch על המבטיחות ביותר

### שלב 3 — Filter & Rank

**קריטריוני איכות:**

| מאפיין | דירוג |
|--------|--------|
| מקורות ראשוניים (מחקרים, אתרים רשמיים) | ★★★★★ |
| פרסומים מקצועיים מובילים (Anthropic, TechCrunch, וכו') | ★★★★ |
| בלוגים מקצועיים, evergreen | ★★★ |
| תוכן אגרגטור / כללי | ★★ — לא נשמר |
| Clickbait / AI-generated גנרי / פורומים | ★ — נדחה |

**העדפות:**
- תאריך פרסום עדכני (12 חודשים אחרונים) אלא אם evergreen
- עברית כשרלוונטי לקהל ישראלי, אנגלית default

### שלב 4 — Save sources

**כל מקור עם דירוג ★★★ ומעלה** → קובץ ב-Content/.

**שם הקובץ:** `Content/<YYYY-MM-DD>-<slug>.md`

**תוכן הקובץ:**
```markdown
---
source_url: https://example.com/article
source_title: Original Article Title
fetched_date: 2026-05-06
quality: ★★★★ (4/5)
language: en
slug: ai-agents-2026
---

# Original Article Title

[התוכן המלא של המאמר]
```

### שלב 5 — Memory log

הוסף entry ל-`chen/Memory/searches.md`:

```markdown
## YYYY-MM-DD HH:MM | <נושא החיפוש>
**מילות מפתח:** keyword1, keyword2
**שאילתות שנעשו:** "query 1", "query 2"
**מקורות שנמצאו:**
- [כותרת](URL) — איכות: ★★★★ — <הערה>
- [כותרת](URL) — איכות: ★★★ — <הערה>
**נבחרו:** N מקורות (★★★+)
**קבצים ב-Content:**
- `Content/YYYY-MM-DD-slug1.md`
- `Content/YYYY-MM-DD-slug2.md`
---
```

### שלב 6 — Report

החזר לממוקה בפורמט סטנדרטי, כולל:
- רשימת קבצים שיצרה ב-Content/
- דירוג לכל קובץ
- לינקים למקור המקורי
- הערה אם השתמשה ב-cache או חיפשה מחדש

## ממוקה Updates

### חן בסוכני-משנה:
```
### חן (chen) — חוקרת רשת
Triggers עברית: חפש, מצא, מחקר, מאמר על, חדש על, מה קורה עם, מקור על
Triggers English: search, find, research, article about, latest on, news on
```

### פרוטוקול chen→yael (auto-pipeline):

**אם הבקשה המקורית של המשתמש כללה חיפוש + שכתוב/פרסום:**
1. הפעל חן עם הנושא
2. קבל רשימת קבצים + דירוגים
3. בחר את הקובץ עם הדירוג הגבוה ביותר (★★★★★ עדיף; אם אין — ★★★★)
4. הפעל יעל על הקובץ הנבחר
5. המשך לפרוטוקול IMAGE_NEEDED הקיים

**אם הבקשה המקורית כללה רק חיפוש ("מצא לי מאמר על X"):**
- דווח למשתמש: רשימת הקבצים שחן יצרה + דירוגים
- שאל: "להמשיך לשכתוב באמצעות יעל?"
- חכה לאישור לפני הפעלת יעל

### Agent Selection Logic (עדכון):
```
האם הבקשה כוללת חיפוש מידע / מקור / מחקר?
  └── כן → הפעל חן (chen)
  
האם הבקשה כוללת שכתוב/עריכה ויש קובץ ב-Content/?
  └── כן → הפעל יעל (yael)

האם הבקשה כוללת חיפוש + שכתוב?
  └── כן → chen → yael auto-pipeline
```

## Constraints

- חן **לא מפעילה** סוכנים אחרים — רק ממוקה
- חן **לא מוחקת** — Memory היא append-only
- חן **לא ממציאה** מקורות — אם לא נמצאו ★★★+ → דיווח על כשלון
- חן **לא יוצרת תמונות** — לא ניגשת ל-OpenAI API
- כל קובץ ב-Content/ חייב YAML frontmatter עם source_url + quality
