# Skill: finishing-a-development-branch

## מה הskill עושה
מנחה את תהליך סיום branch פיתוח: בדיקות, קוד נקי, PR.

## למי שייך
Claude — מופעל בסיום עבודה על feature branch לפני merge.

## שלבים עיקריים
1. הרצת בדיקות
2. בדיקת קוד נקי (lint, types)
3. עדכון תיעוד
4. commit ו-push
5. פתיחת PR
