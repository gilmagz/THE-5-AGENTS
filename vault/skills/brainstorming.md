# Skill: brainstorming

## מה הskill עושה
הופך רעיונות לעיצובים מלאים דרך דיאלוג. **חובה לפעיל לפני כל כתיבת קוד.**

## למי שייך
Claude — מופעל לפני כל עבודה יצירתית: פיצ'רים חדשים, שינוי התנהגות, בניית רכיבים.

## זרימה
`הבנת הרעיון` → `שאלות הבהרה (אחת בכל פעם)` → `2-3 גישות` → `עיצוב` → `אישור` → `כתיבת spec` → `[[skills/writing-plans]]`

## כלל קריטי
HARD-GATE: **לא לכתוב קוד** לפני שהמשתמש אישר את העיצוב.
